# Aura Botanica (Nuxt)

Boutique e-commerce **Aura Botanica** — Nuxt 4, **shadcn-vue**, **French** and **Arabic** only (`@nuxtjs/i18n`).

## Run

```bash
npm install
npm run dev
```

- French (default): `http://localhost:3000/`
- Arabic (RTL): `http://localhost:3000/ar`

## Stack

- Nuxt 4 + Vue 3
- Tailwind CSS v4 + botanical design tokens
- shadcn-vue (Button, Card, Sheet, Dialog, Sonner, …)
- i18n: `i18n/locales/fr.json`, `i18n/locales/ar.json`
- Cart / account / checkout demo (localStorage)
